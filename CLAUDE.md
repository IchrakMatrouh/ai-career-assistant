# AI Portfolio

## Project Overview

This project is a modern AI-powered personal portfolio website developed as the capstone project for the FlyRank Front-end AI Engineering Internship.

The portfolio showcases my skills, projects, education, certifications, and experience while integrating AI features to improve user interaction.
