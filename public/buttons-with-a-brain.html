Buttons with a Brain

Stateful interactive buttons that choreograph idle → hover/focus → active → loading → success/error → idle using compositor-only properties (transform & opacity).

Interactive Component System State: idle (20% random fail)

Duration & Easing Rationale

Tactile Responsiveness (160ms): Hover lift (translateY(-2px)) and press compression (scale(0.97)) use 160ms cubic-bezier(0.22, 1, 0.36, 1) (exponential ease-out). Direct pointer and keyboard interactions require near-instantaneous feedback so the control feels physically connected to the user's input.

State Choreography (260ms & 380ms): Lifecycle swaps (idle → loading → success/error → idle) cross-fade over 260ms with subtle vertical translation so outgoing and incoming labels overlap smoothly without snapping. Error states trigger a damped 380ms horizontal shake that draws attention to failure without jarring the layout.

Zero Layout Thrash & Accessibility: Every state layer shares a single CSS Grid cell (grid-area: 1 / 1), keeping dimensions locked while animating exclusively GPU-composited properties (transform and opacity). Monotonic run IDs ensure spam-clicking never breaks transitions, and prefers-reduced-motion: reduce suppresses spatial movement while preserving color, icon, and aria-live status updates.
